## Project Idea

- Name: Knock Knock
- Tagline: "Know who's at the door before the knock knock!"
- Initial idea: An AI-powered facial-recognition experience for homes and businesses. For the hackathon, the demonstration focuses on daily private-family use. Ring events provide freeze frames; the app attempts to match previously user-verified identities and prompts the user to categorize and tag unknown visitors.
- Product principle: Matching is advisory. The user verifies identities and remains the authority over labels.
